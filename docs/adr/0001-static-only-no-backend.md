# Static-only: Sky keeps no backend

Sky is a personal fork of openGym (v1.2.9 baseline) that deliberately deletes the entire server era — `api/`, `web/`, `mcp/`, `website/`, docker-compose, Docker/CI configs — keeping only the React PWA as a static build that runs anywhere static files run. The upstream product's value (passkey auth, multi-user sync, admin, web push) all depends on a server a single user won't operate; the app is fully usable offline with device-local storage because every feature already worked against local state, so removing the backend costs little and eliminates deployment, hosting, and security surface entirely. Consequence: features that *need* a server (accounts, sync between devices, server-scheduled notifications) are permanently out of scope rather than deferred.
