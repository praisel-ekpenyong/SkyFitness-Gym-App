# The Milestone cue reads the Prescription

The live Milestone cue had its own Hit rule, including a weight gate the Prescription does not use, so a badge could promise an advance the Session boundary would not grant. The cue now uses the Prescription's judgement. A lighter Row that still reaches the target reps is a Hit. Rep progress and an unlocked advance are read on the last planned Work set as if that session had just ended. A hold or a Deload stays on the Progression summary. The cue keeps no second Hit rule.

## Considered options

A cue-local weight gate, so a lighter performed Row withholds the unlock even when the Prescription would advance. Rejected: the badge and the next Prescription would keep disagreeing.
