Honest questions

OfflineDoes it work without a connection?

Yes. After first load the network is optional. Exercise media streams when available and falls back quietly. Your log never waits for a server because there is none.

PriceWhat does Sky cost?

Nothing. It is a static build with no accounts to bill and no cloud to rent. Export and import stay free because they are files, not services.

SafetyWhere does my data live?

On your device, mirrored between local storage and a native file. A backup reminder appears if 14 days pass without an export.

HistoryCan I bring my old logs?

FitNotes, Strong, Hevy and Apple Health imports merge with your profile. Existing days win, so nothing duplicates.

NumbersWhy does it sometimes show a dash?

A missing value is a dash, never a guess. One-rep estimates stop above 12 reps, where the formulas diverge, and averages wait for enough rated sets.
